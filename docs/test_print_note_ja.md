# テスト造形のご案内（第1回）

**対象：** Socket、BallStud、EarPiece の3点
**目的：** ボール圧入時のひずみ判定と、シリコンイヤーピースの嵌合確認

---

## 1. なぜ3点なのか

ご依頼は Socket と EarPiece の2点でしたが、**BallStud を追加**しています。

ソケットのひずみ検証には「Φ18mmの球体」を圧入する必要があり、その相手部品が
BallStud です。これが無いと検証そのものが行えません。市販のΦ18mm鋼球でも
代用できますが、実機と同じ樹脂どうしの嵌合を見るには BallStud の造形を
お勧めします。

また EarPiece のねじ（M10×1.5、造形品）の噛み合いも、BallStud があれば
同時に確認できます。造形高さ18mm・体積4.8cm³の小部品ですので、追加負担は
わずかです。

---

## 2. 造形条件

| 部品 | 造形高さ | 底面 | 備考 |
|---|---:|---|---|
| Socket | 27.63 mm | 43.9 × 27.7 mm | 3点中で最も高い |
| BallStud | 18.00 mm | 42.5 × 18.0 mm | |
| EarPiece | 14.98 mm | 24.0 × 15.0 mm | |

STLは**すでに平置き姿勢に回転済み**です。そのまま配置してください。
3点同時造形の場合、造形高さは27.63mmとなります。

### サポート材の除去について

以下は内部にサポート材が入ります。除去が不十分だと嵌合しません。

- **Socket の球面座**（内部のため目視が困難です。特に入念に洗浄してください）
- Socket の割りスリット4本と応力逃げ穴
- Socket 外周のねじ山（M27.7×2.0）
- BallStud のねじ山（M10×1.5）
- EarPiece のねじ穴（M10×1.5、深さ11mm）

---

## 3. 確認いただきたい項目

### 3-1. Socket：ボール圧入（最重要）

**これが今回の主目的です。**

爪1本あたり1.45mm撓ませてΦ18mmのボールを圧入します。根元の曲げひずみは
計算上2.8%で、硬質樹脂の破壊ひずみ3〜4%に対して余裕が約1.4倍しかありません。

　確認事項：
　- ボールが入るか（入らない／割れる／入る、のいずれか）
　- 割れた場合、**どこが割れたか**（爪の根元か、応力逃げ穴か、それ以外か）
　- 入った場合、手で引いて抜けないか
　- 挿入時の感触（軽い／固い／かなり力が要る）

　割れた場合も**失敗ではありません。**口部角度を広げる対策（+9.6°）を
　用意してありますので、ご報告いただければ調整版をお出しします。

### 3-2. Socket ＋ Collar のねじ

今回 Collar は含めておりませんが、Socket 外周のねじ山が造形上どう出るか
（山が潰れていないか、サポート材が残っていないか）をご確認ください。
次回の造形判断に使います。

### 3-3. EarPiece：シリコンイヤーピースの嵌合

　ノズル寸法：軸径Φ4.5 / 返しΦ5.5 / 長さ6.0mm（ご指定どおり）

　確認事項：
　- お使いのイヤーピース（標準サイズ）が**手で押し込めるか**
　- 押し込んだあと、**引いて抜けないか**
　- シリコンの土台がΦ15ストッパーの面に**平らに着座するか**
　- ノズルが長すぎる／短すぎることはないか

　返しの締め代は半径で0.5mmとしています。固すぎる場合はΦ5.3に、
　緩い場合はΦ5.7に変更できます。

### 3-4. EarPiece ＋ BallStud のねじ

　- M10×1.5のねじが噛み合うか
　- 最後まで締まり、ストッパー面が振れずに回るか

---

## 4. ご報告いただきたい内容

| 項目 | 内容 |
|---|---|
| 判定 | 各項目の可否 |
| 割れた場合 | 割れた位置の写真 |
| 寸法 | 可能であればノズル軸径とソケット球面座の実測値 |
| 感触 | 圧入・ねじ込みの手応え |

実測値をいただければ、造形の収縮傾向を織り込んで隙間を調整できます。

---

## 5. 調整可能な箇所（ご報告後にこちらで対応します）

| 症状 | 調整するパラメータ | 現在値 |
|---|---|---|
| ボールが入らない／割れる | ソケット口部角度 | +0°（最大+9.6°まで） |
| ボールが緩い | 球面座の隙間 | 半径0.25mm |
| ねじが入らない | ねじの隙間 | 半径0.20mm |
| イヤーピースが固い／緩い | 返し径 | Φ5.5 |
| イヤーピースが奥まで入らない | ノズル長さ | 6.0mm |

いずれも1行の変更で再出力できます。
